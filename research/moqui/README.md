# Moqui and Mantle corpus

Issue [34](https://github.com/EnzoTironi/OS/issues/34). Parent [2](https://github.com/EnzoTironi/OS/issues/2).

These notes mine Moqui Framework and Mantle as an independent enterprise lineage. They extract concepts and behavior. They do not copy implementation.

`docs/swarm-result-contract.md` is not on this branch. The notes follow the Agent output contract in `docs/swarm-research-backlog.md` and use the record IDs from pull request 84 so a later index can ingest them.

## How to read

Start with the primary evidence note. Use the other files as lookup tables.

- `../notes/issue-0034-moqui-mantle-archaeology.md` is the cited evidence note.
- `domain-atlas.md` maps Party, Product, Asset, Order, Shipment, Invoice, Payment, Inventory, and WorkEffort.
- `service-action-pattern-catalog.md` sorts Service patterns by how close they are to a first-class Action.
- `invariants.md` lists candidate invariants with decision state.
- `erpnext-odoo-moqui-convergence-matrix.md` is the three-way comparison.
